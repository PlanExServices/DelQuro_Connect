# DelQuro Connect native client

This Expo project is the local starter for the iPhone and Android teammate app. It has not yet been connected to the service or built for devices. The intended enrollment, workstation approval, session, and on-site Chat alert flow is in [the design document](../docs/WORKSTATION_MOBILE_AUTH_DESIGN.md).

Dependencies are installed locally. Before device testing, the app needs a private HTTPS service URL, device enrollment, and development builds for push notifications and background geofencing. Do not publish a build or point it at a production service without approval.
